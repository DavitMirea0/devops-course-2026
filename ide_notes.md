# Git в VS Code и терминале

В VS Code удобно:
1. Просматривать список измененных файлов в Source Control.
2. Сравнивать версии файла рядом и видеть добавленные и удаленные строки.
3. Выбирать отдельные изменения для включения в коммит.

В терминале удобнее выполнять последовательность команд Git и повторять ее на удаленном сервере через SSH.
